# Warren Boffet

A deliberately unserious, interactive meme website built for Robinhood Chain culture.

## Run locally

Open `index.html` directly, or serve the folder with:

```bash
python -m http.server 8765
```

Then visit `http://127.0.0.1:8765`.

## Stack

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- Original AI-generated meme artwork
